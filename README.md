# 🧠 ForgetAI

A project demonstrating **Digital Forgetting in AI** using importance, usage, and time decay.

## 🚀 Features
- Intelligent memory scoring
- Automatic forgetting of low-value data
- AI comparison (Normal AI vs ForgetAI)
- Real-time dashboard & analytics
- Memory optimization demo

## 🧠 Concept
Inspired by human memory, this system:
- Retains important information
- Removes outdated/irrelevant data
- Improves efficiency and scalability

## ⚙️ Tech Stack
- Frontend: React.js
- Backend: Node.js, Express
- Database: MongoDB
- AI: Gemini API
